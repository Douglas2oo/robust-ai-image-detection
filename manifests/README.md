# 数据划分清单

清单由 `scripts/prepare_data.py` 一次性生成（随机种子 2026）并冻结

## 文件

| 文件                                                                      | 内容                                                                                      | 数量                |
| ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | ------------------- |
| `train.csv`                                                               | 官方 train 分区，100 个 ImageNet 类，真实图 + SD1.4，按类平衡（每类每标签 142 张）        | 28,400（各 14,200） |
| `val.csv`                                                                 | 官方 train 分区中与训练集不重叠的部分（每类每标签 20 张）；只用于选参、早停、校准、定阈值 | 4,000（各 2,000）   |
| `test_sd14.csv`                                                           | 官方 val 分区：1000 张真实图 + 1000 张 SD1.4（已见生成器）                                | 2,000               |
| `test_sd15.csv`、`test_midjourney.csv`、`test_adm.csv`、`test_biggan.csv` | 同一组 1000 张真实图 + 1000 张该生成器的图（未见生成器）                                  | 各 2,000            |
| `audit.csv`                                                               | 每个划分 × 来源的格式、分辨率、类别数统计                                                 |                     |
| `report.json`                                                             | 生成参数、各目录扫描数量、去重数量、最终数量                                              |                     |
| `classes.json`                                                            | 选中的 100 个类（ImageNet 索引和 wnid）                                                   |                     |


## 字段

| 字段                     | 含义                                                                                  |
| ------------------------ | ------------------------------------------------------------------------------------- |
| `relpath`                | 相对于数据根目录的图片路径（唯一，可作为图片 ID；同一张真实图在各测试清单中路径相同） |
| `label`                  | 0 = Real，1 = AI                                                                      |
| `source`                 | `real` 或生成器名（`sd14`、`sd15`、`adm`、`midjourney`、`biggan`）                    |
| `split`                  | `train`、`val` 或 `test`                                                              |
| `cls`                    | ImageNet 类别索引（0–999）；测试清单为空                                              |
| `fmt`、`width`、`height` | 文件格式和原始尺寸                                                                    |
| `phash`                  | 64 位感知哈希，用于去重                                                               |

训练和评测只使用 `relpath` 和 `label`（以及用于标注的 `source`）
