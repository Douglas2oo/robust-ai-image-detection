# 数据划分清单

此目录纳入 Git，原始图片位于被忽略的 `data/` 目录。清单使用 UTF-8 CSV 和相对于 `data.root` 的路径，不记录个人机器的绝对路径。

建议生成：

- `train.csv`：真实图片＋SD 1.4，来自官方训练分区。
- `val.csv`：来自官方训练分区的独立验证子集。
- `test_real.csv`：固定的真实测试图片。
- `test_sd14.csv`、`test_sd15.csv`、`test_adm.csv`、`test_midjourney.csv`、`test_biggan.csv`：各来源合成测试图片。
- 外部数据集另建清单；保留其真实/合成来源映射并单独报告。

目前只提供字段约定，不创建空白或虚构的数据清单。后续评测实现需支持将固定真实清单与对应生成器清单配对。

| 字段 | 含义 |
| --- | --- |
| image_id | 稳定且唯一的图像标识；同一真实图片跨测试组合保持同一 ID |
| relative_path | 相对于数据根目录的图片路径 |
| label | 0=Real，1=AI |
| generator | 真实图片填写 real，合成图片填写实际生成器 |
| semantic_class | 语义类别；外部数据无对应类别时可为空 |
| split | train、val 或 test |
| duplicate_group | 相同或近重复图片的分组标识 |

划分前执行原图 ID、精确重复和感知哈希检查，同一个重复组不可跨 train/val/test。处理生成器文件夹中重复出现的真实图片。记录类别、来源、格式、分辨率及去重后的数量；训练与测试类别范围需要事先固定。官方 val 分区作为本项目测试来源，不能误作调参验证集。

划分冻结后记录清单版本或文件哈希，训练和评测直接读取清单，不能自行重新抽样划分。
